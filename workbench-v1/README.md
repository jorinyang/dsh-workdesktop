# dsh-workbench-v1（弈枢 · 工作台 1.0）

> 工作台的 **1.0** 实现：按 **采集器 / 处理器 / 存储器** 三部分重建。
> 本包只含**引擎与页面**，不含任何数据 —— 所有内容来自你本机的知识库目录。

## 它解决什么问题

旧版工作台是"一屏 13 张卡"：卡名与顺序被**六处以上**声明钉死（含一份外部锚点），
2026-09-17 一次改名让 9 条真机断言整批假红。1.0 把两件事分开：

- **引擎**（采集 / 筛选 / 分析 / 处理 / 存储）—— 只认事件与契约
- **页面**（五个业务页 + 驾驶舱）—— 只认"页面集合与顺序"，且**收敛到 `pages.mjs` 一个文件**

## 三部分各自干什么

| 部分 | 目录 | 职责 |
|---|---|---|
| **采集器** | `collector/` | 多通道采集与**每 5 分钟轮询**；水位线保证幂等（**出错绝不前进**）；模态转换（语音→文字、图片视频→文件、文件不变） |
| **处理器** | `processor/` | **筛选**（双写知识库 JSONL+MD · 意图判定 · 链接队列）→ **分析**（知识库召回 + 按类分流）→ **处理**（自动关闭与归档） |
| **存储器** | `storage/` `api/cockpit.mjs` | 周期沉淀（每日核对向量化 · 每周萃取方法论/知识/模型 · 每月 review 时间切片）· 驾驶舱（数据统计/知识图谱/发展趋势/业务洞察/状态分析/发展建议） |

## 怎么跑

```bash
# 1) 自检（不需要知识库：会自己造临时运行态）
node selftest-all.mjs              # 期望 PASS = 335   FAIL = 0

# 2) 采集一轮（需要知识库根）
node collector/run.mjs

# 3) 本地接口（只监听 127.0.0.1；只放行 write-routes.json 里登记过的写路径）
node api/server.mjs 8791

# 4) 渲染页面到 <知识库>/Other/data/workbench-v1/
node ui/preview.mjs
node ui/cockpit-page.mjs
```

### 两个路径，别混（`paths.mjs` 是唯一定义处）

| 概念 | 环境变量 | 默认 | 说明 |
|---|---|---|---|
| **包根** `PKG_ROOT` | 无 | 本包目录 | **包内资源**（`contract.json`、`write-routes.json`）一律相对它 |
| **知识库根** `KB_ROOT` | `WB_V1_KB_ROOT` | 自动向上识别（判据：同时存在 `_meta` 与 `Work`） | **包外资源**（`_meta/out/**`、`Other/**`、RAG 桥）相对它 |
| 运行态 | `WB_V1_OUT` | `<KB_ROOT>/_meta/out/v1` | 可写目录 |

**找不到知识库根时会直接报错，不会猜** —— 猜错会往无关目录里写文件。

> 为什么专门做这件事：本包早先按"我住在 `_meta/workbench/v1/<子目录>/`"这个**嵌套深度**往上数知识库根，
> 整体挪个位置就 **318 PASS / 17 FAIL**（`write-routes.json` 指到包外）。
> 收口后**原地与独立两种跑法都是 335/0**。

## 它**复用**了知识库侧的什么（这些不在包内）

- **RAG 桥**（`<KB>/_meta/workbench/rag-bridge.mjs`）：召回层用它做向量检索，召回门槛 **0.55**（实测本库相似度挤在 0.59–0.66 的窄带，旧写死 0.60 会丢掉真命中）
- **索引器**（知识库自带，每日 03:00）：本包**不重写索引**，只做新鲜度核对 —— 两处各写一遍索引必然漂移
- 听记镜像（`Other/Input/钉钉听记/*.md`）与邮件收据（`_meta/out/mail-receipts.json`）作为现成输入

## 两条既有判定规则（1.0 保留）

1. **回复即已回复**：我在对应沟通工具里回复过相关信息 ⇒ 消息视为已回复
2. **交付即完成**：知识库或沟通上下文中已交付结果性物料、并完成既定动作 ⇒ 待办视为已完成
   （检测节点：**创建待办时** 与 **每日知识库沉淀时**）

## 几条不肯让步的纪律

- **写路径必须先登记**（`write-routes.json`）：未登记的写请求一律 404，读路径守同一条纪律
- **写接口只落运行态**，双写知识库归筛选引擎 —— 不出现第二处实现
- **召回失败 ≠ 没有上下文**：桥断了要写明原因，绝不显示成"暂无相关材料"
- **模型失败不落盘、没数据不调模型** —— 否则页面会显示"看似有内容的空分析"，这是最难查的假错
- **能量化的都量化**：错误率阈值、召回门槛、自动关闭条件都写死并配负向对照
